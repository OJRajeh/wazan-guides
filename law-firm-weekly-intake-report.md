# What a managing partner should see in a weekly intake report

If the only time you look at intake numbers is when something feels wrong, you are reacting late. A short report that arrives at the same time every week lets you spot a problem while it is small.

## Keep it to one screen

A weekly report should be readable in a couple of minutes. These are the numbers worth including.

**1. New leads, by practice area.** How many came in this week and last week.

**2. Lead source.** Where each lead came from: referral, website, directory, ads, or other. This only works if source is captured as a fixed list at intake. See [how to qualify leads at intake](/wazan-guides/qualify-law-firm-leads/).

**3. Conversion.** Of the leads that came in, how many became signed matters. Track it by practice area, because one area may convert well and another poorly.

**4. Reasons for loss.** For each lead that did not convert, one reason from a short list: no response, price, conflict, outside practice area, chose another firm, other. Over a few months the list shows what to fix.

**5. Stalled leads.** Qualified leads with no contact in a set number of days, with names, so someone can act on them this week.

## Clean up referral sources first

Referral source data is usually messy, with the same source spelled several ways. Agree on one list and merge old variants before you trust any report built on them.

## Send it where you will read it

A Monday morning email works well because the week's priorities are still open. The report should pull from the system where leads already live, not from a file someone updates by hand.

## What to do with it

Pick one change per month based on the numbers, such as following up faster on one lead source, and check the next month's report to see if it helped.
