# Law firm intake automation: what to automate first

Wazan's view is that many boutique firms have a process problem more than a people problem. The same steps happen by hand every time a lead arrives, a matter opens, or a report is due. Automation helps only when it is aimed at the right step.

## Map the process before choosing a tool

Write down what happens from the moment a lead first contacts you to the moment a matter is open. For each step, note who does it, how long it takes and which software it touches. Two or three hours with the person who handles intake can show where the time leaks.

## Common candidates, in a sensible order

1. **Intake and qualification.** Replace the generic contact form with questions that fit each practice area, so a lead arrives already qualified. See our guide on [qualifying leads before the first call](/wazan-guides/qualify-law-firm-leads/).
2. **Opening a matter.** If the same details are typed into a practice-management system, a conflict check and an engagement letter, one set of answers should feed all three.
3. **Reporting.** A short weekly summary of leads, sources and outcomes, sent automatically, replaces a spreadsheet someone updates when they remember. See [what a weekly intake report should show](/wazan-guides/law-firm-weekly-intake-report/).
4. **Follow-up on stalled leads.** A reminder when a qualified lead has had no contact for a set number of days.

## Automate around the tools you already run

A new system that replaces your practice-management software is a large project. Connecting intake to the practice-management system or spreadsheet you already use is smaller and easier to reverse. Start there.

## Keep a person in the loop where it matters

Automation should prepare and route. Decisions about whether to take a matter, conflict outcomes and anything sent to a client in the firm's name stay with an attorney or staff member.

## Check that it worked

Pick one number before you start, such as time from first contact to first callback, or share of leads that arrive with every required field filled. Measure it before and after. If it did not move, the step you automated was not the bottleneck.
